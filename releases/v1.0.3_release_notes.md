# OpenFXpedia v1.0.3 — Feature and maintenance release

## One-line summary
Add exchange-rate source selection, safer update handling, and more capable currency search.

---

## Highlights
- Added an exchange-rate API selection setting.
- Improved conversion request handling and update-check safety.
- Added ISO numeric currency-code support.
- Improved currency search with clear-search functionality.
- Expanded localization support for accessibility tests and the search bar.

## What’s new
- Exchange rates:
  - Choose the exchange-rate API from Settings.
  - Improve request handling when converting currencies.
- Currency search:
  - Search currencies by ISO numeric code as well as existing identifiers.
  - Clear the current search query directly from the search interface.
- Settings and localization:
  - Make update checks safer.
  - Add localization support for accessibility-test and search-bar text.

## Bug fixes & polish
- Improved the reliability of conversion and update-check flows.
- Made currency discovery easier for users who know a numeric ISO code.

## How to install / assets
Attach platform artifacts to this release (recommended filenames):
- `openfxpedia_1.0.3.apk`
- `openfxpedia_1.0.3.apk.sha1`
- `openfxpedia_1.0.3.exe`
- `openfxpedia_1.0.3_setup.exe`

Portable EXE: `build/windows/portable/`
NSIS installer: `build/windows/installer/` (requires `makensis` on PATH)

## Build commands (for maintainers)
Bash (POSIX):

```bash
./scripts/build_android.sh
./scripts/build_windows.sh
```

PowerShell (Windows):

```powershell
./scripts/build_android.ps1
./scripts/build_windows.ps1
```
