# OpenFXpedia v1.0.7 — Feature and maintenance release

## One-line summary
Explore up to one year of historical exchange rates and review the app's privacy statement in Settings.

---

## Highlights
- Extended historical exchange-rate charts from three months to one year.
- Added an in-app privacy statement in Settings.
- Improved exchange-rate handling, currency metadata, localization, and application state management.
- Updated Android build tooling and added automated platform smoke and release-build workflows.

## What's new
- Historical exchange rates:
  - Expanded the available chart history to one year.
- Privacy:
  - Added a privacy statement accessible from Settings.

## Bug fixes & polish
- Improved exchange-rate provider handling and currency data management.
- Refined application state management and localization.

## How to install / assets
Attach the platform artifacts to this release:
- `openfxpedia_1.0.7.exe` (Windows portable executable, in the portable bundle)
- `openfxpedia_1.0.7_portable.zip` (Windows portable bundle)
- `openfxpedia_1.0.7_setup.exe` (Windows NSIS installer)
- `openfxpedia_1.0.7.apk`
- `openfxpedia_1.0.7.apk.sha1`

Portable EXE: `build/windows/portable/`
Portable bundle: `build/windows/`
NSIS installer: `build/windows/installer/` (requires `makensis` on PATH)
Android APK and SHA-1: `build/app/outputs/flutter-apk/`

## Build commands (for maintainers)

PowerShell (Windows):

```powershell
./scripts/build_android.ps1
./scripts/build_windows.ps1
```
