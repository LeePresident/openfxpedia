# OpenFXpedia v1.0.6 — Feature and maintenance release

## One-line summary
Explore historical exchange rates with charts and combine amounts in different currencies with the new calculator.

---

## Highlights
- Added date-based currency conversion with historical exchange-rate charts and a quick return to the latest rates.
- Added a multi-currency calculator for combining amounts in different currencies.
- Improved conversion reliability, historical rate handling, and calculator layouts on narrow screens.
- Expanded English and Chinese localization and documentation.

## What's new
- Historical exchange rates:
  - Choose a date for a conversion and see the requested and actual rate dates.
  - View exchange-rate history in a chart and quickly return to the latest rates.
- Multi-currency calculator:
  - Enter amounts in different currencies and combine them using a selected target currency.

## Bug fixes & polish
- Improved conversion and rate-history handling.
- Improved calculator layout on narrow screens and refined localized text.

## How to install / assets
Attach the platform artifacts to this release:
- `openfxpedia_1.0.6.exe` (Windows portable executable, in the portable bundle)
- `openfxpedia_1.0.6_portable.zip` (Windows portable bundle)
- `openfxpedia_1.0.6_setup.exe` (Windows NSIS installer)
- `openfxpedia_1.0.6.apk`
- `openfxpedia_1.0.6.apk.sha1`

Portable EXE: `build/windows/portable/`
Portable bundle: `build/windows/`
NSIS installer: `build/windows/installer/` (requires `makensis` on PATH)
Android APK and SHA-1: `build/app/outputs/flutter-apk/`
