# OpenFXpedia v1.0.5 — Feature and maintenance release

## One-line summary
Add currency-unit and denomination details with converter shortcuts, plus a way to clear locally stored app data.

---

## Highlights
- Added major and minor currency units and coin/banknote denominations to currency details.
- Added denomination shortcuts that open the converter with the matching currency and amount.
- Added a Settings action to clear locally cached rates, currency data, and saved preferences.
- Improved Chinese localization, application performance, and automated test setup.

## What's new
- Currency details:
  - Display major and minor units, coin denominations, and banknote denominations.
  - Select a supported denomination to open the converter with its currency and amount.
- Settings:
  - Clear locally cached exchange rates, currency catalog data, and saved preferences.

## Bug fixes & polish
- Improved Chinese localization and application performance.
- Updated automated test setup and project maintenance.

## How to install / assets
Attach platform artifacts to this release (recommended filenames):
- `openfxpedia_1.0.5_portable.zip` (Windows portable app bundle)
- `openfxpedia_1.0.5.apk`
- `openfxpedia_1.0.5.apk.sha1`
- `openfxpedia_1.0.5_setup.exe`

Portable bundle: `build/windows/` (contains the EXE and required runtime files)
NSIS installer: `build/windows/installer/` (requires `makensis` on PATH)
Android APK: `build/app/outputs/flutter-apk/`

## Build commands (for maintainers)
Bash (POSIX):

```bash
./scripts/build_android.sh
./scripts/build_windows.sh
```

PowerShell (Windows):

```powershell
./scripts/build_android.ps1
./scripts/build_windows.ps1
```
