# OpenFXpedia v1.0.8 — Feature and maintenance release

## One-line summary
Use OpenFXpedia on Linux, compare multiple currencies, and search currencies more responsively.

---

## Highlights
- Added Linux desktop support with versioned x86_64 release bundles.
- Added a multi-currency comparison screen.
- Improved currency search responsiveness with indexing and debouncing.
- Added right-to-left language support and native-language names in the language selector.
- Improved Android in-app updates and localization integration.

## What's new
- Linux desktop:
  - Added x86_64 release bundles for supported Ubuntu LTS and Debian stable versions.
- Multi-currency comparison:
  - Added a screen for comparing conversions across multiple currencies.
- Search and languages:
  - Added indexed currency search and debounced calculations.
  - Added right-to-left layout support and display of language names in their native scripts.

## Bug fixes & polish
- Corrected the Android in-app update flow.
- Modernized UI and localization integration and updated currency search behavior.

## How to install / assets
Attach the platform artifacts to this release:
- `openfxpedia_1.0.8.exe` (Windows portable executable, in the portable bundle)
- `openfxpedia_1.0.8_portable.zip` (Windows portable bundle)
- `openfxpedia_1.0.8_setup.exe` (Windows NSIS installer)
- `openfxpedia_1.0.8.apk`
- `openfxpedia_1.0.8.apk.sha1`
- `openfxpedia_1.0.8_linux_x64.tar.gz` (Linux x86_64 bundle)

Portable EXE: `build/windows/portable/`
Portable bundle: `build/windows/`
NSIS installer: `build/windows/installer/` (requires `makensis` on PATH)
Android APK and SHA-1: `build/app/outputs/flutter-apk/`
Linux bundle: `build/linux/`

## Build commands (for maintainers)

PowerShell (Windows):

```powershell
./scripts/build_android.ps1
./scripts/build_windows.ps1
```

Linux:

```bash
bash ./scripts/build_linux.sh
```
