# OpenFXpedia v1.0.4 — Feature and maintenance release

## One-line summary
Add richer currency-region details and encyclopedia controls while improving Windows launch and installation reliability.

---

## Highlights
- Added region flags and expandable region lists to currency details, with reliable flag display in Chinese locales.
- Added currency sorting by code or name and a favorites-only encyclopedia filter.
- Improved duplicate-launch handling and the Windows installer flow when OpenFXpedia is already running.
- Simplified currency asset conventions and polished localized interface and changelog text.

## What’s new
- Currency details:
  - View flags for the regions where each currency is used.
  - Expand or collapse long region lists without leaving the currency detail view.
  - Display region flags reliably when using Simplified or Traditional Chinese.
- Currency encyclopedia:
  - Sort currencies by ISO code or localized name in ascending or descending order.
  - Filter the encyclopedia to show favorite currencies only.
- Windows experience:
  - Handle duplicate application launches more reliably.
  - Detect a running OpenFXpedia process during installation and offer to close it before continuing.

## Bug fixes & polish
- Simplified currency flag and icon asset conventions.
- Improved localized changelog labels, descriptions, and related interface text.
- Updated project guidance and documentation to reflect current asset behavior.

## How to install / assets
Attach platform artifacts to this release (recommended filenames):
- `openfxpedia_1.0.4.apk`
- `openfxpedia_1.0.4.apk.sha1`
- `openfxpedia_1.0.4.exe`
- `openfxpedia_1.0.4_setup.exe`

Portable EXE: `build/windows/portable/`
NSIS installer: `build/windows/installer/` (requires `makensis` on PATH)

## Build commands (for maintainers)
